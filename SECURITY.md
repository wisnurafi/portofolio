# Security Policy

This is a static portfolio site — no backend, no database, no auth,
no user input beyond links. The attack surface is about as small as a
website gets. Still, if you find something, I'd rather hear about it
privately.

## Reporting

Open a **private security advisory** on GitHub, or email me directly
(the address is on the site's contact section). Don't open a public
issue for security reports.

Include what you found, where, and how to reproduce it. Screenshots
help.

## Scope

In scope: this site's code and content — the Next.js app, its config,
anything served from the domain.

Out of scope:

- GitHub or the hosting platform itself. Report those to GitHub /
  the provider, not to me.
- The hotlinked project screenshots (they're served by GitHub's CDN).
- Social engineering or anything targeting me personally.

## What to expect

Indie project, no bug bounty, no SLA. I'll acknowledge your report,
fix confirmed issues, and credit you unless you'd rather stay
anonymous.
